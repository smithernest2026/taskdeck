# TaskDeck

A local-first project & task tracker built with React, TypeScript, and Vite.
All data lives in the browser (localStorage) — no backend, no accounts.

## Features

- Dashboard with live task statistics
- Task table with sorting, search filtering, selection, and bulk actions
- Create, edit, and delete tasks
- Projects to group tasks
- Light / dark theme

## Requirements

- Node.js 20 (see `.nvmrc`)
- npm

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Script              | Description                        |
| ------------------- | ---------------------------------- |
| `npm run dev`       | Start the Vite dev server          |
| `npm run build`     | Type-check and build for production |
| `npm run preview`   | Preview the production build       |
| `npm run lint`      | Run ESLint                         |
| `npm run typecheck` | Type-check without emitting        |
| `npm test`          | Run the Vitest suite               |
